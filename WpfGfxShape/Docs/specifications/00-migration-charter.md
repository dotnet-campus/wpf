## 用户强制纠正：生产禁止原版媒体委托
禁止生产保留或加载任何原版 wpfgfx 提供媒体服务；允许 Windows 公开媒体组件。既有生产“合法第二wpfgfx”许可已撤销，历史绿不认证独立媒体。删除链路与当时普通媒体创建 E_NOTIMPL、独立媒体 Open / NotImplemented 属于下述删除报告的历史截点，不认证当前实现状态。官方必须在独立对照进程参加与候选相同测试，不属于被禁的生产委托；禁止同进程双版本、fallback及候选专属补偿。见[删除报告](../history/completed-work/replacement-remove-original-media-delegation.md)。

强制执行；适用于 WpfGfxShape 全部调查、设计、实现、测试和交接。
目标源码 `src/Microsoft.DotNet.Wpf/src/WpfGfx` 及直接依赖、生成协议、托管调用方。
生产根 `WpfGfxShape/Code/WpfGfxShape`；主测试根 `WpfGfxShape/Tests/WpfGfxShape.Tests`；文档根 `WpfGfxShape/Docs`。
